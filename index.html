Selective Toxic Knowledge Removal from Pre-trained LLMs

I investigate full-parameter selective unlearning: updating model weights to reduce unwanted toxic-language behaviour while preserving useful knowledge and general model capability.

Research workflow

Define evaluation baselinesMeasure model utility and unsafe-generation behaviour before intervention.
02
Prepare selective datasetsSeparate forget, retain, control and evaluation data with clear roles.
03
Update model parametersApply controlled full-parameter optimization with utility protection.

01

Model behaviour, not filters

The research studies changes to model parameters rather than relying only on output blocking or prompt filtering.

02

Utility matters

Reducing unsafe behaviour is only useful when the model continues to provide coherent and useful responses.

03

Reproducible evaluation

Generation settings, datasets and evaluation protocols need to remain controlled for meaningful comparisons.
